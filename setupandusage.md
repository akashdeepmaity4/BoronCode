## SETUP

###  For Windows Users:
 - Download the Latest release from Github Releases.
 - Run the installer wizard and follow the instructions.

 OR 

 - Download the codebase.
 - Run 'makeexecutable.sh' in root directory of the codebase using bash.

 OR 
 - Download the codebase.
 Run launcher.py to launch the PWA (entire codebase should be downloaded to prevent any errors)

```bash
cd path/to/root/directory
python launcher.py
```

### For Linux / Mac Users:

- Download the codebase.
- Run launcher.py to launch the PWA (entire codebase should be downloaded to prevent any errors)

```bash
cd path/to/root/directory
python launcher.py
```
