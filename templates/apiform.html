AI Hub

This feature does not run the model by itself. You must start a local AI server first.

  1. Download a local model in GGUF or other supported format.
  2. Run a local AI server such as LM Studio, llama.cpp, or a compatible OpenAI-style backend.
  3. Start the server on localhost, for example http://localhost:1234/v1 or http://localhost:8080/v1.
  4. Keep the model file on disk and note the exact path.
  5. Paste the model file path into the field above or select it with Browse.
  6. Enter the gateway URL that your server exposes.
  7. Use the model name your server expects, if required.
  8. Press Load Model and then ask your question in the AI popup.
  9. If the server is offline, the app cannot run the model by itself.

Select folder(s) to automatically search for local AI model files (.gguf, .bin, .safetensors, .onnx, .pth, .pt)
